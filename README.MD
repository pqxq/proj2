# Програмний проєкт 2. Дослідження паралельних алгоритмів мови С++.

## Варіант 5: Пошук мінімального елемента (std::min_element)

* **Виконав:** Величко Максим, К-24
* **Цільовий стандарт:** C++23
* **Компілятор:** GCC 13.2+ / Clang 17.0+
* **Система збирання:** CMake 3.25+

---

## 1. Постановка задачі

Дослідити швидкодію оп	ерації пошуку мінімального елемента у масиві цілих чисел на різних обсягах даних ($10^5$	, 		$10^6$, 	$10^7$ елементів):

1. **Бібліотечний алгоритм за відсутності політики:** послідовний виклик `std::min_element`.
2. **Бібліотечний алгоритм з політиками виконання:** `std::execution::seq`, `std::execution::par`, `std::execution::par_unseq`.
3. **Власний паралельний алгоритм:** розбиття вибірки на $K$ частин однакової довжини, обробка кожної частини в окремому потоці (`std::jthread`) послідовним алгоритмом, зведення локальних мінімумів фінальним послідовним викликом.
4. **Оцінка ефективності:** виведення залежності часу від $K$, визначення оптимуму $K_{opt}$ та його співвідношення з апаратною кількістю потоків процесора (`std::thread::hardware_concurrency()`), а також порівняння швидкодії при різних предикатах та рівнях оптимізації (`-O0` vs `-O3`).

---

## 2. Реалізація паралельних алгоритмів та засобів C++23

* **Власний паралельний алгоритм (`custom_parallel_min`):**
  * Рівномірний розподіл залишкових елементів між $K$ частинами.
  * Використання асинхронних RAII-потоків `std::jthread` з явним очікуванням `join()`.
  * Фінальна редукція масиву локальних результатів послідовним `std::min_element`.
* **Стандартні політики виконання (`<execution>`):**
  * Застосування `std::execution::par` та `std::execution::par_unseq` у поєднанні з Intel TBB.
* **Генерація та збереження даних (`<random>`):**
  * Послідовності генеруються 64-бітним генератором `std::mt19937_64` з фіксованим сидом і попередньо зберігаються у текстові файли `data_100k.txt`, `data_1m.txt`, `data_10m.txt` для забезпечення ідентичності всіх експериментів.
* **Оброблення помилок:**
  * Перехоплення винятків відкриття файлів та валідація вхідних даних у блоці `try-catch` у `main()`.
